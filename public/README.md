# public/

## logo.png — the company mark

Save the LinkD artwork here as **`logo.png`**, at roughly 600px wide with a
transparent background.

It is used in three places, all of which reference `/logo.png`:

- the printed evaluation sheet's letterhead
- the printed cycle summary
- the sidebar and the sign-in screen

**Nothing breaks if it is missing.** Every use carries the company name as its
`alt` text, so the mark degrades to a wordmark rather than to a broken-image
icon — the sheet looks unbranded, not broken.

A dark-background variant can go beside it as `logo-invert.png` if the navy
sidebar ever needs one; the current mark reads well on it as is.
